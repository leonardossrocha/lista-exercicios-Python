## 📖 Visão Geral
Este repositório centraliza todas as atividades práticas, desafios lógicos e listas de exercícios desenvolvidos ao longo da Unidade Curricular de Desenvolvimento em Python[cite: 3]. O propósito deste ambiente é estritamente **acadêmico e científico**, servindo como um portfólio de evolução técnica dos estudantes[cite: 3]. O foco é transcender a mera digitação de código, promovendo a aplicação do método científico na resolução de problemas e a construção de arquiteturas de software seguras.

## 🎯 Objetivos
* Consolidar a sintaxe da linguagem Python e as boas práticas de codificação.
* Desenvolver o raciocínio lógico-matemático através de algoritmos de complexidade .
* Fomentar a autonomia digital e a revisão de código por pares.

## 🧠 Conteúdo Programático
Os scripts aqui armazenados cobrem os seguintes domínios técnicos:
* Fundamentos (I/O), tipagem dinâmica, variáveis e conversão de dados.
* Tomada de decisão lógica (`if`, `elif`, `else`) e operadores relacionais.
* Automação e repetição finita/condicional (`for` e `while`).
* Estruturas de coleções de dados (Listas e Dicionários).
* Modularização de código (`def`) e blindagem contra travamentos (`try/except`).

## ⚙️ Metodologia
Os exercícios listados neste repositório são resolvidos utilizando metodologias ativas no laboratório:
* **Aprendizagem Baseada em Problemas (PBL):** Exercícios contextualizados em cenários de negócio (ex: startup fictícia ArkeTech).
* **Pair Programming (Programação em Duplas):** Revezamento contínuo entre piloto e copiloto adaptado para as estações de trabalho fixas do laboratório.
* **Code Review:** Auditoria de código cruzada entre as equipes para identificação de falhas e debates lógicos.
