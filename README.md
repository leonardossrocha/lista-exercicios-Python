## 📖 Visão Geral
Este repositório centraliza todas as atividades práticas, desafios lógicos e listas de exercícios desenvolvidos ao longo da Unidade Curricular de Desenvolvimento em Python[cite: 3]. O propósito deste ambiente é estritamente **acadêmico e científico**, servindo como um portfólio de evolução técnica dos estudantes[cite: 3]. O foco é transcender a mera digitação de código, promovendo a aplicação do método científico na resolução de problemas e a construção de arquiteturas de software seguras.

## 🎯 Objetivos
* Consolidar a sintaxe da linguagem Python e as boas práticas de codificação[cite: 3].
* Desenvolver o raciocínio lógico-matemático através de algoritmos de complexidade progressiva[cite: 3].
* Fomentar a autonomia digital e a revisão de código por pares[cite: 3].

## 🧠 Conteúdo Programático
Os scripts aqui armazenados cobrem os seguintes domínios técnicos[cite: 3]:
* Fundamentos (I/O), tipagem dinâmica, variáveis e conversão de dados[cite: 3].
* Tomada de decisão lógica (`if`, `elif`, `else`) e operadores relacionais[cite: 3].
* Automação e repetição finita/condicional (`for` e `while`)[cite: 3].
* Estruturas de coleções de dados (Listas e Dicionários)[cite: 3].
* Modularização de código (`def`) e blindagem contra travamentos (`try/except`)[cite: 3].

## ⚙️ Metodologia
Os exercícios listados neste repositório são resolvidos utilizando metodologias ativas no laboratório:
* **Aprendizagem Baseada em Problemas (PBL):** Exercícios contextualizados em cenários de negócio (ex: startup fictícia ArkeTech)[cite: 3].
* **Pair Programming (Programação em Duplas):** Revezamento contínuo entre piloto e copiloto adaptado para as estações de trabalho fixas do laboratório[cite: 3].
* **Code Review:** Auditoria de código cruzada entre as equipes para identificação de falhas e debates lógicos[cite: 3].
